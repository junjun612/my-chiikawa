# my-chiikawa

나만의 먼작귀 만들기 — 간단한 성향 테스트로 나를 닮은 작고 귀여운 친구를 만드는 웹페이지입니다.

- `index.html` — 성향 테스트: 이름·생년월일 → 8문항 → 결과 캐릭터 (랜덤으로 돌리기 / 이미지 저장)
- `maker.html` — 파츠를 직접 골라 꾸미는 메이커

## 실행

이미지 저장은 로컬 서버에서만 동작합니다.

```
python -m http.server
```

브라우저에서 http://localhost:8000을 엽니다.

## 구조

- `engine.js` — 파츠 합성 엔진 (메이커·테스트 공용)
- `parts.js`, `parts/` — 파츠 이미지와 부착점 데이터
- `quiz-data.js` — 문항, 16가지 유형, 성향별 파츠 범위
- `naming.js` — 이름·생년월일·성향을 시드로 쓰는 별명 생성과 조합 필터
- `result-card.js` — 화면의 설명·태그·탄생 컬러를 같은 배치로 저장하는 카드 하단 렌더러
- `backgrounds/` — 배경 일러스트
- `fonts.css`, `fonts/` — 감자꽃마을(제목·버튼·이름)과 고운돋움(설명·태그)

캐릭터의 배경별 라이팅은 공용 Canvas 렌더러에서 35% 강도로 합성하며, Safari에서도 SVG/Canvas 필터 지원 여부에 영향을 받지 않습니다. 몸 색은 밝은 파스텔 팔레트를 사용하고 5월의 탄생 컬러는 우유 민트입니다.

별명은 본명에서 딴 이름 60%, 성향별 이름 30%, 특별한 이름 10% 비중으로 뽑습니다. 한글 이름의 끝 두 글자를 활용하되 거친 받침, 반복되는 소리, 어색한 단어 조합은 후보에서 제외합니다. 본명 후보가 없는 영문·숫자·이모지 입력에는 성향별·특별 이름을 사용합니다. 같은 입력은 같은 첫 별명이 나오며, 다시 메뉴의 ‘이름만 다시’는 외형을 유지하고 직전과 다른 별명을 뽑습니다.

저장 이미지와 카카오톡 공유 이미지는 같은 카드 생성 함수를 사용합니다. 카드 하단은 화면과 같은 설명 줄바꿈, 성향 태그와 현재 컬러 안내를 담으며 배경 선택 목록은 포함하지 않습니다.

배경은 `viewport-fit=cover`와 고정 레이어로 화면 가장자리까지 이어집니다. 결과 화면은 안전 영역과 현재 화면 높이에 맞춰 카드·버튼을 함께 축소하고 가운데 배치합니다.

## 에셋과 검증

파츠는 몸통 30종, 귀·머리 장식·표정·소품 각각 36종, 등/꼬리 32종으로 총 206종입니다. 공룡 꼬리를 제외한 기존 103종에서 두 배로 확장했습니다. 기존 그림체를 참조한 4×4 생성 시트를 잘라 사용하며, 원본·프롬프트·검수 자료는 `design/expansion/`에 보관합니다.

파츠는 최대 384px의 무손실 WebP, 배경은 최대 768px, 페이지 배경은 최대 720×1280px입니다. `parts.js`의 크기·부착점은 디자인 좌표이므로 실제 이미지 해상도와 다를 수 있습니다. 첫 화면이 그려진 뒤 4개씩 HTTP 캐시에 미리 불러오고, 해석한 이미지와 합성 레이어 캐시는 각각 96개로 제한합니다. 모든 파츠·배경·썸네일은 `engine.js`의 `ASSET_VERSION`을 공유합니다.

새 원본 PNG/JPEG를 추가했다면 Pillow가 설치된 환경에서 `python3 tools/optimize_assets.py`로 변환할 수 있습니다. 변환을 검증한 뒤 원본을 WebP로 교체합니다.

`python3 tools/validate_parts.py`는 파츠 개수, 파일 경로, WebP 형식, 투명도, 해상도와 마스크 정렬을 검사합니다. 생성 메타데이터를 다시 적용하려면 `node tools/merge_parts.js`를 실행합니다.

로컬 서버 실행 후 `/tests/rendering.html`에서 필터 미지원 환경, 라이팅 강도, 화면·저장 일치, 손·소품 겹침과 귀 색상을 확인할 수 있습니다. `/tests/flow.html`은 실제 8문항 진행, 이름만 다시 짓기, 랜덤 몸 색 변경, 배경 유지, PNG 카드 생성과 처음부터 다시 기능을 검증합니다. `/tests/catalog.html`은 모든 파츠를 포함한 192개 조합을 8개 배경에 합성해 시각 검수용 목록을 만듭니다.

`node --test tests/naming.test.js`는 별명 재현성, 발음 필터, 입력 예외, 성향별 다양성과 중복 방지를 검증합니다.

감자꽃마을은 [Google Fonts 공식 배포본](https://github.com/google/fonts/tree/main/ofl/gamjaflower)을 한글 전체 음절과 기본 문자로 서브셋한 웹폰트입니다. 라이선스는 `fonts/OFL-GamjaFlower.txt`에 포함했습니다.

팬 메이드 비공식 프로젝트이며, 파츠·배경은 원작 이미지를 쓰지 않고 새로 생성한 오리지널 그림입니다.
