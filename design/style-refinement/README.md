# 먼작귀 스타일 선별·교체

사용자가 제공한 캐릭터 예시와 [공식 캐릭터 소개](https://www.chiikawaofficial.com/characters/)를 함께 비교했습니다. 아래 기준은 이미지의 형태를 직접 비교해 정한 프로젝트 디자인 판단입니다.

- 머리와 몸이 자연스럽게 이어지는 둥근 체형과 작고 모인 손발
- 아래로 살짝 좁아지는 몸선, 부드러운 볼살과 간결한 손그림 외곽선
- 눈·입을 작고 단순하게 유지하고, 큰 별·하트 동공은 기존 표현용 파츠로 제한
- 복슬한 바디와 귀는 보존하되 본체를 가리는 거대한 도형·꽃 코스튬은 제외
- 장식은 캐릭터보다 먼저 눈에 들어오지 않는 크기로 합성해 판단

## 선별 범위

바디 30종 중 17종은 유지하고 9종을 교체하며 4종은 제외해 최종 26종으로 정리합니다. 식빵·마시멜로의 각진 모양, 과한 가로 납작형, 아래가 더 넓은 배 모양, 주먹밥·기운 콩 모양 6종과 비슷한 둥근 형태 3종을 새로 그립니다. 기존 햄스터와 좋은 복슬·동물 무늬는 유지합니다.

제외하는 `body_18`, `body_22`, `body_26`, `body_31`은 동물보다 구름·푸딩 같은 도형으로 읽히거나 다른 바디와 겹치는 형태입니다. `body_04`는 중복 후보로 검토했으나 형태 자체가 좋은 복슬 바디여서 보존합니다.

체형을 한 가지로 통일하지 않고 둥근 몽글이, 통통한 햄스터, 큰 머리 아래 작은 몸이 구분되는 동물형, 볼 옆 털의 모몽가형과 짧은 겉털의 수달형을 섞습니다. 작은 무늬와 다른 발·팔 자세도 포함합니다. 소품은 중앙에만 놓지 않고 실제 쥐는 손의 위치와 손목 각도로 붙이며, `anchors.face`와 `anchors.prop`의 네 번째 값은 회전 각도입니다.

새 9종은 실제 머리 폭·두피 위치·기울기를 따로 측정해 귀 간격과 각도, 얼굴·볼터치·머리 장식의 회전을 맞춥니다. `anchors.head`가 이 머리 좌표계이며 `anchors.earScale`은 머리 폭을 따르는 귀의 크기입니다.

한 손 체형 7종은 바깥으로 뻗은 손에 소품을 들게 합니다. 아래쪽 손에 소품을 달고 위쪽 손은 비어 있던 6종을 추가로 고쳐, 뻗은 손은 작은 그립으로 바꾸고 반대 손은 몸 옆에서 쉬는 모양으로 정리합니다. 이미 맞춘 `body_25`와 중앙에서 두 손으로 안는 체형은 유지합니다.

귀는 뾰족한 박쥐 모양 1종을 교체하고 사막여우 귀의 크기를 줄입니다. 신규 표정 `19–36`은 과장된 눈과 반짝임을 다시 검토해 작은 눈·간결한 눈썹과 입으로 정리합니다. 기존 `01–18` 표정은 유지합니다.

머리 장식 1종과 등/꼬리 3종은 날카로운 뿔·화살·날개를 작고 부드러운 그림으로 교체합니다. 긴 귀와 겹쳐 다섯 갈래 뿔처럼 보이던 `deco_09` 깃털은 기존의 65%로 줄입니다. 본체를 큰 틀에 넣는 `back_10`, `back_11`, `back_12`, `back_30`, `back_31`, `back_32`는 제외합니다. 특히 큰 구름 후드 두 종은 복슬한 바디와 달리 몸을 꽃틀에 끼운 모양이 되어 제거합니다. 동물 특징으로 읽히는 사자 갈기는 유지합니다. 소품 36종은 모두 확인했으며 작은 음식·책·생활용품을 단순한 선으로 그린 기존 방향이 잘 맞아 유지합니다. 전체 소품 검수 이미지는 `prop-audit.jpg`입니다.

최종 카탈로그는 총 196종입니다. 변경 ID와 이유, 생성 프롬프트, 원본 시트와 전후 합성은 각 폴더에 보관합니다. 생성에는 내장 `image_gen`을 사용하며 사용자 요청에 따라 4×4 투명 시트에서 선별해 잘라 사용합니다.

## 적용과 검증

`catalog.json`이 최신 교체 매니페스트와 제외 목록을 정합니다. `node tools/merge_parts.js`는 최초 확장 데이터 다음에 이 보정을 적용하므로 실행을 반복해도 제외한 파츠가 돌아오지 않습니다. `python3 tools/validate_parts.py`로 WebP·크기·투명도·마스크 정합성을 검사합니다.

바뀐 바디는 귀·표정·소품과 다시 합성하고, 전체 파츠를 포함한 랜덤 조합은 실제 Canvas 렌더러로 검수합니다. 교체 후에도 최대 384px WebP 규격과 공용 캐시 버전·프리로드 경로를 유지합니다.

`anchors.propOffsets`는 소품별 `[dx, dy, 추가 회전, 크기 배율]`입니다. 이동량은 몸통 원본 디자인 좌표로 기록합니다. 새 한 손 자세에서는 소품의 일부분만 잡도록 테두리를 맞추고, 일부 긴 소품은 손잡이·줄기에 손이 닿도록 보정합니다. 두 손 체형은 중앙에서 음식·인형을 안거나 먹는 느낌을 유지합니다. 이때 입 근처의 겹침은 의도된 표현으로 허용합니다.

사용자 피드백에 따라 두 손 소품을 일괄적으로 옆으로 내리던 보정은 채택하지 않습니다. `rejected-adjustments.json`에 해당 실험 파일을 기록했으며, 최종 병합 대상은 `catalog.json`의 `propOffsets` 목록입니다. 얼굴 알파 간섭 검사는 시각 검수의 참고 자료로 사용합니다.

`back_08`은 추가 귀처럼 보이던 날개를 72%로, `back_17`은 그림 아래에서 잘리던 물고기 꼬리를 62%로 줄입니다. 생성 이미지의 원본을 바꾸지 않고 부착 크기를 조정합니다.

`tests/style-review.html`은 교체·크기 조정 전후의 36종 비교와 새로운 9개 자세·소품 36조합을 실제 엔진으로 합성합니다. `before-catalog.json`과 `baseline/`은 스타일 정리 직전 커밋의 데이터와 이미지이며 비교 용도로만 사용합니다.

추가 손 방향 보정은 `body/raised-hand-replacements.json`의 6종에 적용합니다. 기존 아래쪽 손을 기준으로 만든 줄기·볼 간섭 보정은 더 이상 병합하지 않으며, 최종 소품 좌표는 `body/hand-offsets.json` 한 파일로 통합합니다. `body_25`의 도넛 좌표 `[-39, -24]`와 기존 그림은 보존합니다. `hand-direction-comparison.jpg`는 6종의 도넛·샌드위치 전후 24합성이며, `final-look-preview.png`는 양손 보존 예시와 한 손 7종의 최종 모습입니다.

## 최종 검수 결과

- 한 손 7종 × 소품 36종 = 252조합 및 두 손 2종 × 36종 = 72조합, 총 324개 실제 Canvas 합성 확인. 손잡이는 줄기에서, 넓은 소품은 가장자리에서 잡도록 확인했습니다.
- 최종 랜덤 1,024조합을 16장으로 저장하고 나눠 시각 검수했습니다. 렌더링 오류 0건이며 명백한 부유·추가 팔·잘림·눈/귀 부착 오류는 발견하지 못했습니다. 중앙에서 안거나 먹는 입 근처의 겹침은 의도된 표현입니다.
- 레이아웃 5,000개와 개별 부착 4,420개에서 비정상 수치·누락된 성격 테스트 파츠 참조가 없습니다. `node design/style-refinement/validate-layouts.js`로 재검사합니다.
- 196개 파츠가 참조하는 WebP 620개의 투명도·크기·마스크 정합성 검사 통과. 생성 이미지도 기존 최대 384px 규격이며 프리로드는 공용 캐시 버전 `20261020-style4`를 사용합니다.
- 렌더링·결과 흐름·꾸미기 41개 검사와 Node 테스트 10개 통과. 병합 도구 재실행 시 같은 카탈로그를 유지합니다.

실제 꾸미기 화면은 `final-maker-preview.png`, 최종 랜덤 기록은 `random-review.json`과 `random-review-01.jpg`–`16.jpg`, 소품 접점 기록은 `body/raised-hand-calibration.json`에 있습니다.
